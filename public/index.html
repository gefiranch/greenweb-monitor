    How the estimate works

    SWDM v4
    01 / MEASURE

    Test the page

    Google PageSpeed Insights runs a mobile Lighthouse performance audit. Transfer size comes from the total network payload in bytes.

    02 / ESTIMATE

    Model the footprint

    CO2.js uses the Sustainable Web Design Model v4 to estimate grams of CO₂e per visit from those bytes.

    03 / INTERPRET

    Understand the limits

    Green hosting is unverified, so the model uses its non-green assumption. Results vary by test conditions and are estimates.
