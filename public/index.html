    Sustainable Web Design Model v4
    How the estimate works

    Google PageSpeed Insights runs a mobile Lighthouse audit. CO2.js uses its total network payload in bytes to estimate grams of CO₂e per visit with the Sustainable Web Design Model v4.

    Green hosting is unverified, so the model uses its non-green assumption. This does not establish the website’s actual energy source. Results vary with test conditions.
